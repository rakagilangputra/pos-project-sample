# Validation

Use this folder for browser walkthroughs before client demos. Each walkthrough
should describe the starting data, actions, expected visible result, and any
known prototype limitations.

The authoritative verification commands are in `AGENTS.md`:

```powershell
npm run lint
npm run build
```

For interactive validation, start the app with `npm.cmd run dev` and open
`http://localhost:3000`. Do not treat a successful build as proof that the
workflow is usable; complete the browser walkthrough as a real cashier or
store operator.
